# automated_server_backup_script
- A Bash script designed to make life easier for DevOps teams by automating PostgreSQL database backups.
- It securely sends backups via email and provides notifications for both success and failure events, ensuring peace of mind during off-hours.

**Features**  
- Automated database backups based on your cron job configuration
- Added delay feature to prevent spamming
- Secure delivery via email to an address of your choice
- Notifications for success or failure on either mail or sms based on your service provider
- Easy to configure and run
